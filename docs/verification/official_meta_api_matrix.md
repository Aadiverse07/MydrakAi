## Cross-cutting API facts

- Authentication docs require an API key in `Authorization: Bearer ...`, recommend environment variables/secrets managers, separate keys, and prohibit committing credentials. No key was read or tested. See [Authentication](https://dev.meta.ai/docs/authentication).
- Docs list `https://api.meta.ai/v1` as the base URL and document Responses, Chat Completions, and Messages-compatible APIs. SDK compatibility does not prove every model accepts every request feature; consult each capability guide.
- Official pricing says pay-as-you-go applies to Model API and also to Muse Code when using API billing; Muse Code also has separate subscription plans. [Muse Code subscriptions](https://dev.meta.ai/docs/muse-code/subscriptions) state the subscription credential is for Muse Code only; additional API keys are pay-as-you-go.
- The official [Model API Terms](https://dev.meta.ai/legal/terms-of-service) say Standard content is not used to train Meta models, while content may be retained as needed for service, law, rights, safety/security and policy review. Contributor mode grants training use. [ZDR help](https://dev.meta.ai/help/policies-and-privacy/zero-data-retention) says ZDR requires separate approval and may not support some models/features; it is not the default.
- No official source reviewed defines a special exception permitting private farmer photographs in Contributor mode. Project policy is stricter: private photos must only use the verified non-contributor/Standard path. The current foundation has no client or enforcement code, so this is a future implementation requirement.
- **Credits:** official Meta event pages say participants can receive free Model API credits, but this review found no primary-source statement confirming the amount, allocation, expiry, or coverage by each model/mode. The reported $149.65 balance remains user-reported and account-specific.
