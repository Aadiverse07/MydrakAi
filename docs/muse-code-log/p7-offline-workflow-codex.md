## Acceptance and implementation

Added `run_synthetic_mock_workflow(photo_bytes, language, ...)` in
`src/mydrak/workflow/pipeline.py`. Byte-based header validation and preprocessing
reuse the existing PNG/JPEG bounds, EXIF handling, measurements, normalization,
and image hash without creating a temporary file. The privacy/data-policy gate
runs before pixel preprocessing and all mock provider calls. A denied or invalid
input stops safely and is traced.

Only `DeterministicMockDiagnosisProvider` and
`DeterministicMockSamProvider` are accepted. Glimmer outputs use the existing
B8 schema validator and bounded repair. The workflow extracts S1/S2 and calls
the unchanged `route_signals()`. Ordinary routing leaves S3 unavailable and S4
unmapped, so it refers. `TestOnlySignalOverride` supplies labeled synthetic
S2/S3/S4 values for branch integration tests; it is not read from configuration.
The existing `config/thresholds.yaml` placeholders are not tuned or promoted to
approved values. A route requesting Spark calls the mock once, then re-scores
using the unchanged Glimmer S1, Spark-derived synthetic S2, and test-only S3/S4.
Spark failure refers; unavailable Glimmer goes directly to one Spark attempt,
then refers without fabricating evidence.

SAM fixtures are parsed through `parse_sam_output()` and decoded only as the
project-local `synthetic-grid-v1` format. Existing T08 severity and renderer
functions produce the synthetic severity band and in-memory watermarked overlay.
Empty or failed masks return no severity/overlay and a fixed explanatory reply
line. No provider mask format or response-text/Base85 decoding is implemented.

KB answer/question text comes only from `tests/fixtures/kb/SYNTHETIC_TEST.yaml`
validated with `allow_synthetic_test=True`; production `load_disease_card()` is
unchanged and continues rejecting this fixture. Replies are English-only and
include `SYNTHETIC / MOCK`, preliminary-guidance language, a confidence-vocabulary
term, and the safety line. Hindi remains unreviewed and returns no localized
reply. Invalid bytes/policy return a traced blocked result; B3 retake is terminal.

`MockWorkflowCache` is process-local and keys normalized image hash, language,
policy, hashed user identity, and test override. A hit returns the stored mock
result without any Glimmer/Spark/SAM call and still creates a new case, steps,
and signals trace. Trace tables contain hashes, safe route values, and fixed
step metadata; no photo bytes, reply text, provider text, or raw user ID is
stored. This is not persistent B9/T15 caching.
